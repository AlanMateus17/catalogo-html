5.1 As suas cores

O estilo.css da estrutura começa com as variáveis de cor. Troque pelos códigos das suas cores (um site como coolors.co ajuda a escolher):

Exemplo em css/estilo.css

:root {
  --cor-principal: #5a189a;  /* cabeçalho, botões, links */
  --cor-destaque: #ff9e00;   /* realces */
  --cor-fundo: #f7f4fb;
  --cor-texto: #1d1330;
}

Os códigos prontos usam cores fixas, como #12324a. Troque pelas variáveis, var(--cor-principal), e o site inteiro passa a seguir as suas cores.

Confira: qual a vantagem de escrever var(--cor-principal) em vez de #5a189a em cada regra?

Ver a resposta

Se um dia você quiser outra cor, troca uma linha só, no :root, e todas as regras mudam juntas.

5.3 Conferir no celular sem ter um celular

  1. No navegador, aperte F12 e depois Ctrl + Shift + M.
  2. No topo, escolha uma largura de celular, como 390.
  3. Role a página toda. Se aparecer rolagem para o lado ou algo cortado, é ali que precisa de ajuste.

Erro comum: mudei o CSS e nada aconteceu.

Clique com o botão direito no elemento e escolha Inspecionar. À direita aparecem todas as regras que valem para ele. Uma regra riscada está perdendo para outra mais forte ou que vem depois no arquivo.

Erro comum: a imagem de fundo do CSS não aparece.

Dentro do CSS, o caminho parte da pasta css. O certo é url("../img/foto.jpg"): o ../ volta uma pasta antes de entrar em img.

Você tenta

Escreva três regras suas, que não vieram prontas: um :hover diferente nos links, uma borda nos títulos h2 e uma cor de fundo alternada nas seções (section:nth-child(even)).

Pronto quando

Marque cada item só depois de conferir. As marcações ficam salvas neste navegador e aparecem na página inicial da trilha.
