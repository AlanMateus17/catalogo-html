# Catálogo do HTML

Site didático para aprender a criar sites e sistemas: passo a passo do computador vazio ao site no ar, documentação de HTML, CSS e JavaScript, códigos prontos comentados, verificador de projeto e dicionário. Feito pelo Prof. Alan Mateus para os alunos do Técnico em Informática e em Desenvolvimento de Sistemas.

- **Comece aqui:** abra `passo-a-passo.html` (a trilha em 10 passos).
- **Guia completo do que tem em cada arquivo:** [`LEIA-ME.txt`](LEIA-ME.txt).
- **Plataforma que vende e libera o curso:** repositório [catalogo-plataforma](https://github.com/AlanMateus17/catalogo-plataforma).
